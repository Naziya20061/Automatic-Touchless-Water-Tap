# Automatic Touchless Water Tap

## About the Project

The Automatic Touchless Water Tap is a hardware-based project designed to make water dispensing more hygienic and convenient. The system uses an IR sensor to detect the presence of a hand and a solenoid valve to control the flow of water.

The main idea behind this project is to reduce physical contact with taps and avoid unnecessary water wastage. It demonstrates how basic electronic components can be combined to create a practical solution for everyday use.

## Features

* Detects the presence of a hand using an IR sensor.
* Controls water flow using a solenoid valve.
* Uses an electronic switching circuit to operate the valve.
* Reduces the need for physical contact with the tap.
* Demonstrates a practical application of electronic components.

## Components Used

* IR Sensor Module
* 12V Solenoid Valve
* Transistor (BC547 or TIP122)
* 1N4007 Diode
* Relay (if required by the circuit)
* 9V–12V Power Supply
* Resistors, wires, and connectors

## How It Works

When a hand is placed near the tap, the IR sensor detects its presence and sends a signal to the switching circuit. The circuit controls the solenoid valve, allowing water to flow. When the hand is removed, the system is designed to stop the water flow.

This process allows the user to operate the tap without touching it manually.

## Applications

The system can be used in homes, schools, hospitals, public washrooms, and other places where maintaining hygiene is important.

## Learning Outcomes

This project provided practical experience with sensors, electronic switching, solenoid valves, and hardware integration. It also helped us understand how electronic components can be used to address everyday problems.

## Future Improvements

The project could be improved by adding a timer to control the duration of water flow, improving sensor accuracy, and measuring water consumption to evaluate its effectiveness in reducing water wastage.
